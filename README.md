# Data Analytics Portfolio

A collection of analytics projects demonstrating Power BI, API integration, AI-assisted analysis, and dashboard development.

---

## Projects

### Toothpaste Carbon Footprint & Price Dashboard
End-to-end Power BI dashboard comparing six toothpaste brands across retail price and carbon footprint. Built using SerpApi for live price data, Anthropic Claude API for AI-assisted carbon parameter extraction from research PDFs, and DAX for a custom Efficiency Score metric.

[View Project](Toothpaste-Carbon-Dashboard/README.md)

---

### Cheese Packaging A/B Test
A/B test analysis across 1,000 users comparing Transparent versus Covered Packaging. Transparent Packaging delivered 42.9% higher purchase conversion, 28% higher add-to-cart rate, and 39.4% more revenue across the full purchase funnel.

[View Project](Cheese-Packaging/README.md)

---

### Transportation Operations Intelligence Dashboard
Roadway maintenance performance analysis across Interstate 287. Identified high-impact maintenance segments and measured post-maintenance improvements including a 20.5% reduction in congestion and 19.5% increase in average vehicle speed.

[View Project](Transportation-Dashboard/README.md)
